<CardGrid>
	<Card title="Dependencies against Nexus" icon="puzzle">

	</Card>
	<Card title="Parallel builds that explain themselves" icon="rocket">

	</Card>
	<Card title="Branches and safe rebasing" icon="random">

	</Card>
	<Card title="Built for CI" icon="seti:json">
		`pmm doctor` gives one exit code and writes JSON, JUnit XML and a self-contained HTML
		report for the CI factory.
	</Card>
	<Card title="A dashboard in the terminal" icon="laptop">
		`pmm ui` shows the whole workspace on one screen, live builds included, with the actions
		one key away.
	</Card>
	<Card title="One native executable" icon="approve-check">
		Built with GraalVM: `pmm.exe` starts instantly, needs no JVM, and updates itself with
		`pmm self-update`.
	</Card>
